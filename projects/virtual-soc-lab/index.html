SOC ANALYST LAB PROJECT

Virtual SOC Lab

A hands-on Security Operations Center lab built using Wazuh, Ubuntu Server, Windows, Kali Linux, and VirtualBox. The lab is designed to practice security event monitoring, log analysis, alert investigation, and basic incident response in a controlled virtual environment.

Wazuh SIEM Ubuntu Server Windows Kali Linux VirtualBox Log Analysis

Project Overview

The Virtual SOC Lab is a personal cybersecurity learning environment created to understand how security monitoring works in an organization.

Wazuh is deployed on an Ubuntu Server virtual machine. A Windows machine is connected using the Wazuh agent to forward endpoint security events to the manager. Kali Linux is used as a separate security testing machine within the virtual lab.

The purpose of this project is to understand how endpoint events are collected, how security alerts are generated, and how an analyst can investigate suspicious activity.

Lab Architecture

The lab uses virtual machines running in VirtualBox. Each machine has a separate role in the monitoring environment.

Ubuntu Server

Hosts the Wazuh manager and central monitoring components. Receives and processes security events from connected agents.

Windows Endpoint

Runs the Wazuh agent and serves as the monitored endpoint. Generates system and security events for monitoring and investigation.

Kali Linux

Used as a security testing machine for authorized activities in the isolated virtual lab.

VirtualBox Networking

Connects the virtual machines and enables communication between the Wazuh manager, monitored endpoint, and testing machine.

Tools and Technologies

Wazuh

SIEM and XDR platform used for security event collection, endpoint monitoring, alerting, and log analysis.

Ubuntu Server

Linux server environment used to deploy and manage the Wazuh monitoring infrastructure.

Windows

Endpoint operating system used to generate and monitor security-related events.

VirtualBox

Hypervisor used to create and manage the virtual machines and lab network.

Monitoring and Investigation Workflow

The lab follows a basic SOC investigation workflow to understand how an analyst handles security alerts.

01

Log Collection

The Wazuh agent collects configured security and system events from the Windows endpoint and forwards them to the Wazuh manager.

02

Security Event Monitoring

Review the Wazuh dashboard to monitor incoming events, agent status, alert severity, and relevant event details.

03

Alert Triage

Examine an alert's timestamp, source endpoint, rule information, severity, and event description to understand what triggered the detection.

04

Investigation

Review related logs and available evidence to determine whether the activity appears suspicious, requires further investigation, or may be legitimate system behavior.

05

Documentation

Record the observed activity, relevant evidence, investigation steps, and findings in a structured incident investigation format.

Skills Practiced

Log Analysis

Understanding security logs, timestamps, event fields, and endpoint activity.

Alert Triage

Reviewing alert severity, detection rules, and event context.

Incident Investigation

Examining available evidence and documenting investigation findings.

Linux Administration

Practicing Linux server operations and managing a virtual security environment.

Project scope: This is a personal virtual lab for educational and cybersecurity practice. Activities are performed in a controlled environment. Lab simulations and investigation exercises should not be interpreted as professional SOC employment or production incident response experience.
