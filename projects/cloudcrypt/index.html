WEB DEVELOPMENT PROJECT

CloudCrypt

CloudCrypt is a web-based encryption and decryption platform developed to demonstrate cryptographic operations through a simple and interactive interface. The application combines Python Flask, modern web technologies, and cryptographic libraries to provide text encryption and decryption functionality.

Python Flask Cryptography AES / Fernet HTML CSS JavaScript

Project Overview

CloudCrypt is a web application designed to make basic cryptographic operations accessible through a browser-based interface.

The platform demonstrates text transformation using a Caesar cipher, Base64 encoding and decoding, and Fernet-based symmetric encryption and decryption.

The frontend provides an interactive interface for entering text and viewing results, while the Flask backend handles the application logic and cryptographic operations.

Project Objectives

Text Encryption

Demonstrate encryption of text using cryptographic functionality provided by the application.

Text Decryption

Allow users to decrypt compatible encrypted content using the required key or input.

Encoding and Decoding

Demonstrate Base64 encoding and decoding and Caesar cipher transformations.

User Interface

Provide an interactive web interface with a modern design and convenient input and output areas.

Key Features

Fernet Encryption

Uses the Fernet implementation from the Python cryptography library for authenticated symmetric encryption.

Base64 Encoding

Supports encoding and decoding data using the Base64 representation. Base64 is an encoding method, not encryption.

Caesar Cipher

Demonstrates a classical substitution cipher for learning basic encryption concepts.

Modern Interface

Features a responsive web interface with a glassmorphism-inspired design and dark and light themes.

Technology Stack

Python

Implements backend functionality and handles cryptographic operations.

Flask

Handles HTTP requests and connects the frontend with the backend logic.

Cryptography Library

Provides Fernet encryption and decryption functionality in Python.

HTML, CSS and JavaScript

Build the frontend interface, styling, theme controls, and interactive user experience.

Application Workflow

The application follows a straightforward interaction between the user interface and the Flask backend.

01

Input Text

The user enters the text to be processed and selects the required cryptographic operation.

02

Select Operation

The user selects an available operation, such as encryption, decryption, encoding, or decoding.

03

Backend Processing

The Flask application receives the request and processes the input using the selected cryptographic or encoding method.

04

Return Result

The processed result is returned to the frontend and displayed to the user.

Skills Practiced

Backend Development

Building Flask routes and connecting backend operations with a web interface.

Cryptography Fundamentals

Understanding symmetric encryption, encryption keys, encoding, and decryption concepts.

Frontend Development

Designing responsive web interfaces using HTML, CSS, and JavaScript.

Deployment

Deploying a Flask-based web application using a cloud hosting platform.

Security note: CloudCrypt is an educational project demonstrating cryptographic concepts. The Caesar cipher and Base64 are not suitable for protecting sensitive information. Fernet encryption requires secure key management. Do not use the application to protect sensitive data unless its deployment, key handling, and security controls have been independently reviewed.
