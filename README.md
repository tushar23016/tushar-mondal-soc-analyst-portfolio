## Run Locally

This is a static website. No backend or package installation is required to preview the portfolio.

1. Clone the repository:

   ```bash
   git clone https://github.com/tushar23016/AI-Phishing-Detector.git
   ```

   Replace the URL above with the GitHub URL of this portfolio repository if it is stored in a different repository.

2. Open the portfolio folder in Visual Studio Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` and select **Open with Live Server**.

You can also open `index.html` directly in a browser, although Live Server is useful for local development.

## Deploy on Render

This repository is configured for Render Static Site deployment through `render.yaml`.

1. Push the complete website and `render.yaml` to the root of your GitHub repository.
2. Sign in to [Render](https://render.com/).
3. Choose **New → Blueprint** and connect the portfolio repository.
4. Review the detected static site configuration and apply it.
5. After the deployment completes, open the Render URL provided for the service.

Ensure `render.yaml` is in the same directory as `index.html`. All local asset paths used by the website must match the actual file and folder names, including capitalization.
